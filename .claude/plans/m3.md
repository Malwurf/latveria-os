# M3 — limity 5h/7d per profil z obu maszyn w pasku stanu

Design: `../GEM/.claude/designs/latveria-os.md` (§5 M3, §6 „Zrzut limitów”, §7, §10, §11).
Gałąź: `feat/m3-quota` w zwykłym checkoutcie. OpenSpec: zmiana `add-quota-bar`.

## Decyzje właściciela (Open Questions, 16.11)

- Q1 pasek: **klon** wbudowanego `workspace-status` 0.1.16 → `latveria-status` (jeden pasek, tekst 12 px), nie osobny blok.
- Q2 format: **zwięźle** `● Personal 5h 3% · 7d 4%`; czasy do resetu, maszyna i czas ostatniej zmiany w dymku.
- Q4 (design §6): zrzut **tylko przy zmianie**, bez pulsu; **zrzut niesie `label` i `color`**. Skoro bez pulsu wiek
  zrzutu znaczy „od kiedy liczby stoją”, wyszarzenie z dopiskiem `· 2h ago` dostaje tylko maszyna, która przestała być
  osiągalna (§10: śpiący laptop) — jej ostatnie odczyty zostają.
- Q3 kolory: **jak statusline** — < 50 % `working` (zielony), < 80 % stały `WARN` (żółty, test ≥ 4,5:1 na `chrome`),
  ≥ 80 % `blocked`.

## Ustalenia, które kształtują plan

- **Mod nie importuje plików innego modu** (spike 16.11: `herdr-app check` → „resolves outside the application
  directory”). Dlatego pasek nie czyta map profili: **zrzut niesie `label` i `color`** (rozszerzenie addytywne
  kontraktu z §6; kształt `rate_limits` dalej zgodny z Relevo), a `quota.js` ma własną walidację klucza/koloru.
- **Odczyt zrzutów jednym `exec` na maszynę** (lokalnie bez `on`, zdalnie `{on}`): `sh -c` z pętlą po
  `~/.cache/latveria/quota-*.json`, każdy plik `head -c 4096`, najwyżej 32 linie. `readTextFile` nie wylistuje
  folderu, a zdalne `~` rozwija tylko powłoka tamtej maszyny.
- **Tylko przy zmianie** (Q4): zrzut zapisuje się, gdy zmieniły się limity, etykieta albo kolor.
- **Wspólne dopasowanie profilu:** logika z hooka etykiety przechodzi do `hooks/latveria-profile.sh` (wypisuje
  klucz albo nic); hook etykiety i skrypt limitów go wołają. Instalator już kopiuje `hooks/*.sh`.
- `statusline.sh` żyje w konfiguracji Claude właściciela (`home/statusline.sh`, na Macu identyczna kopia w `~/.claude/`, na laptopie
  kopia ręczna). Dostaje jedną linię wołającą `latveria-quota.sh` w tle. Repo `claude` ma teraz gałąź innej sesji
  z niezacommitowanymi zmianami → praca w worktree z `origin/main`, **nigdy `git switch` w tym folderze**.
- Odstępstwo od §7 designu (poziom 1, w opisie PR): `statusline/quota-snapshot.sh` → `hooks/latveria-quota.sh`
  (instalator kopiuje `hooks/`); `mods/latveria-quota/` → `mods/latveria-status/` (Q1).

### T2: `hooks/latveria-quota.sh` — zrzut z JSON-u statusline'u

**Files:** `+ hooks/latveria-quota.sh`, `+ test/quota-snapshot.test.mjs`
**Tests (najpierw, oba shelle, tymczasowy HOME z mapą `Personal`/`Work` z kolorami, stdin = JSON statusline'u):**
1. `rate_limits` 5h/7d → plik `~/.cache/latveria/quota-Personal.json`, jedna linia JSON:
   `{updated:<liczba>, profile:"Personal", label:"Personal", color:"#e3b341", rate_limits:{five_hour:{used_percentage,resets_at}, seven_day:{…}}}`.
2. `CLAUDE_CONFIG_DIR=…/.claude-work` → `quota-Work.json`.
3. Te same limity drugi raz → plik nietknięty (`updated` bez zmian), także gdy w pliku `updated` sprzed godziny.
4. Zmiana koloru profilu w mapie → nowy zapis.
5. Zmiana `used_percentage` → nowy zapis.
6. Tylko `five_hour` → zrzut bez `seven_day`; brak `rate_limits` / `used_percentage` nie liczbą → brak pliku.
7. Zły JSON na stdin, brak mapy, brak dopasowania, brak jq → brak pliku.
8. Zawsze stdout `""` i exit 0; w folderze nie zostaje plik tymczasowy.
**Code (szkielet):**
```sh
#!/bin/sh
# Statusline side-car: reads Claude Code's statusline JSON on stdin and keeps ~/.cache/latveria/quota-<KEY>.json,
# this profile's 5h/7d limits, for Herdr's status bar. No network, no credentials. Writes only when the limits,
# label or color change, through a temp file and mv. Prints nothing, always exits 0.
command -v jq >/dev/null 2>&1 || exit 0
key=$(sh "$(dirname "$0")/latveria-profile.sh")
[ -n "$key" ] || exit 0
map="$HOME/.config/latveria/profiles.json"
dir="$HOME/.cache/latveria"
out="$dir/quota-$key.json"
now=$(date +%s)
snap=$(head -c 1048576 | jq -n -c --arg k "$key" --argjson now "$now" --slurpfile m "$map" 'input |
  def win: if type == "object" and (.used_percentage | type) == "number"
    then {used_percentage, resets_at: (if (.resets_at | type) == "number" then .resets_at else null end)} else null end;
  ((.rate_limits // {}) | {five_hour: (.five_hour | win), seven_day: (.seven_day | win)}
    | with_entries(select(.value != null))) as $r
  | ([$m[0].profiles[]? | select(.key == $k)][0] // {}) as $p
  | if ($r | length) == 0 then empty
    else {updated: $now, profile: $k, label: ($p.label // $k), color: ($p.color // null), rate_limits: $r} end' 2>/dev/null)
[ -n "$snap" ] || exit 0
if [ -r "$out" ] && jq -e -n --slurpfile o "$out" --argjson n "$snap" '$o[0] as $o
  | $o.rate_limits == $n.rate_limits and $o.label == $n.label and $o.color == $n.color' \
  >/dev/null 2>&1; then exit 0; fi
mkdir -p "$dir" 2>/dev/null || exit 0
tmp=$(mktemp "$dir/.quota-$key.XXXXXX" 2>/dev/null) || exit 0
printf '%s\n' "$snap" > "$tmp" && mv -f "$tmp" "$out" # no rm: the rules test bans deleting files
exit 0
```
**Verify:** `node --test test/quota-snapshot.test.mjs` · **Done when:** zielone w sh i dash; `npm test` zielony.

**Checkpoint A:** bramka; `printf '<json>' | sh hooks/latveria-quota.sh` na żywo tworzy plik.
